# Assignment 5 学习与完成指南

## 已确认的作业范围

课程 PDF 和代码骨架要求完成两个核心部分：

1. 在 `Renderer.cpp` 的 `Renderer::Render()` 中，为每个像素生成一条从相机出发的主射线。
2. 在 `Triangle.hpp` 的 `rayTriangleIntersect()` 中，实现 Möller-Trumbore 光线与三角形求交，并更新 `tnear`、`u`、`v`。

作业给出的评分共 30 分：提交格式 5 分、主射线生成 10 分、三角形求交 15 分。反射、折射、Fresnel、阴影、Phong 光照、球体求交和场景遍历都已经由框架提供，本次不要求重新实现。

## 需要掌握的核心知识

### 1. 光线与相机

- 光线参数形式：起点、单位方向和沿光线前进的参数。
- 针孔相机模型，以及相机默认朝向 `-Z` 的含义。
- 如何把整数像素坐标映射到 `[-1, 1]` 附近的成像平面坐标。
- 像素中心偏移、纵轴翻转、视场角缩放和宽高比校正。
- 为什么传给求交代码前需要归一化方向向量。

### 2. 向量运算与重心坐标

- 向量加减、点积、叉积和归一化。
- 叉积如何表达平行性、三角形朝向和有向面积。
- 三角形内部点的重心坐标，以及 `u`、`v`、`1-u-v` 的范围条件。

### 3. Möller-Trumbore 求交

- 把“光线上的点等于三角形内的点”写成关于距离和两个重心坐标的线性方程。
- 用点积与叉积直接求解，避免先求平面交点再做一次内部测试。
- 正确处理平行、三角形外部、交点位于射线后方和更远交点等情况。
- 使用小阈值处理浮点数接近零的问题。

### 4. 读懂框架调用链

建议按以下顺序阅读：

`main()` -> `Renderer::Render()` -> `castRay()` -> `trace()` -> `Object::intersect()`

只需理解框架怎样使用你的结果，不必重写 Whitted-style 递归光线追踪、Phong 着色、反射/折射或阴影逻辑。

## 推荐学习顺序

1. 复习课程 Lecture 13 的第 7-29 页，重点是主射线、光线方程、三角形求交和 Möller-Trumbore。
2. 在纸上画出左上角、中心、右下角像素映射到成像平面的方向，先确认坐标系和正负号。
3. 推导或跟随课程推导 Möller-Trumbore，明确每个中间向量和拒绝条件的几何意义。
4. 先完成主射线，确认能看到两个球；再完成三角形求交，确认棋盘地面出现。
5. 最后检查边界条件、结果图片、`README.md` 和提交目录结构。

Lecture 14 的 BVH、空间划分和辐射度量学是后续知识，本次作业不要求实现，可暂缓学习。

## 本机环境

本工程使用 Windows 11、VS Code、MSYS2 UCRT64、CMake 和 Ninja。不要混用 `C:/mingw64` 或 MSVC 工具链。

在 `Assignment5_code` 中运行：

```powershell
C:/msys64/ucrt64/bin/cmake.exe --preset ucrt-debug --fresh
C:/msys64/ucrt64/bin/cmake.exe --build --preset ucrt-debug
```

也可以在 VS Code 中执行任务 `Assignment5: Build`。完成两个 TODO 后，使用调试配置 `Assignment5：渲染 binary.ppm（完成 TODO 后）`；结果会生成在 `build-ucrt/binary.ppm`。

当前未完成算法时，编译器出现未使用参数以及 `x`、`y` 可能未初始化的警告是预期现象。不要把 `build-ucrt/` 或生成的可执行文件提交到 Git。
